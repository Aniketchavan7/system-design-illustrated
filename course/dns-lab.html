Resolver A’s old answer expired at 60 seconds, so a successful new lookup returns 192.0.2.20. Resolver B cached its answer 10 seconds later. It can still return 192.0.2.10 until 70 seconds.

This model assumes a lookup at the selected time and a reachable authoritative server. It covers DNS answers, so a browser that keeps an existing connection may still use the old endpoint.
