Start with 2,000 incoming requests per second and three servers at 900 each. How many requests per second are left over if one server fails? What happens if the shortfall lasts?

Reveal the worked example

Two surviving servers can handle 1,800 requests per second, leaving a shortfall of 200. A queue can absorb a brief spike if it has time to drain. For sustained overload, add capacity or reject enough low-priority traffic.

The model assumes equally capable servers, evenly distributed traffic, and a load balancer that has already detected the failures. It counts requests rather than estimating latency.
